# Workflow skills

`engineering`, `supervise` and `hashimoto-review` are unchanged copies from
[marashiai/skills](https://github.com/marashiai/skills/tree/ef83e8e1d3a914de5ee79ff99521bf90dc0cd4f3),
pinned at `ef83e8e1d3a914de5ee79ff99521bf90dc0cd4f3`. They are bundled so
sessions do not depend on a network fetch or the user's personal skills install.
Update these copies together from a reviewed upstream revision.

Cerebro skills describe command syntax, role boundaries and durable child
lifecycle. Engineering policy belongs upstream. The parent loads only the
workflow it needs; writable children receive engineering, and `review --explain`
adds Hashimoto review. Selecting `supervise` means unattended execution.
