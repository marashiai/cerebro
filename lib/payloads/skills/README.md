# Role and development skills

`cerebro-supervisor` is the runtime supervisor context. Implementor and reviewer
prompts are task-local and do not inject development skills or review ceremonies.

`engineering`, `supervise`, and `hashimoto-review` remain unchanged repository
development instruction sources referenced by AGENTS.md. They are copies from
[marashiai/skills](https://github.com/marashiai/skills/tree/ef83e8e1d3a914de5ee79ff99521bf90dc0cd4f3),
pinned at `ef83e8e1d3a914de5ee79ff99521bf90dc0cd4f3`. Update these copies together
from a reviewed upstream revision. Cerebro does not automatically install them
into native runtime skill discovery or require their ceremonies.
